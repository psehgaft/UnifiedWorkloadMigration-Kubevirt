Suggested two-day flow

Prepare the cluster in advance so lab time stays focused on workloads.

Day 1 · Containers and Kubernetes

  • Build and run a container image
  • Deploy and expose an application
  • Test Service discovery and network policy
  • Verify data persistence after Pod replacement

Day 2 · Virtual machines on Kubernetes

  • KubeVirt architecture and readiness
  • OpenShift Virtualization or upstream KubeVirt path
  • VM lifecycle and operational practices
  • Functional VM capstone and troubleshooting
Final hands-on exercise

Boot it. Serve it. Prove it.

Use CDI to import a cloud-init-ready qcow2 image. Start a VM with persistent storage, install and run Apache httpd inside the guest, then reach the page through a Kubernetes Service.
